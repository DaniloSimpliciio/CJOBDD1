# CJOBDD1 – Cálculo Relacional

Repositório de atividade acadêmica desenvolvida durante o curso de Análise e Desenvolvimento de Sistemas no Instituto Federal de São Paulo (IFSP).

## Sobre a atividade

Pesquisa acadêmica sobre cálculo relacional, com foco no estudo dos fundamentos teóricos utilizados na área de bancos de dados relacionais.

## Objetivos

- Compreender os conceitos de cálculo relacional.
- Estudar os fundamentos dos bancos de dados relacionais.
- Conhecer formas de representação e consulta de informações.
- Aprofundar conhecimentos sobre a teoria de bancos de dados.

## Conteúdo

Material de pesquisa e estudo desenvolvido como parte das atividades acadêmicas.
